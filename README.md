# Desarrollo Orientado a Objetos II

Proyecto incremental SpeedFast para las actividades semanales de la asignatura.

## Estructura

- `s1/SpeedFastS1`: versión utilizada para las semanas 1 y 2.
- `s3/SpeedFastSemana3`: versión integral solicitada para la semana 3.

## Avance

- Semana 1: sobrecarga, sobrescritura y asignación de repartidores.
- Semana 2: clase abstracta y cálculo del tiempo estimado de entrega.
- Semana 3: interfaces, reserva, despacho, cancelación e historial de pedidos.
