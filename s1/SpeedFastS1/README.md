# SpeedFast

Proyecto incremental de Desarrollo Orientado a Objetos II.

## Semana 2

La clase `Pedido` es abstracta y define los datos comunes, `mostrarResumen()` y
`calcularTiempoEntrega()`. Cada tipo de pedido implementa su propio cálculo.

## Ejecución

Abre el proyecto en IntelliJ IDEA y ejecuta `app.Main`.
